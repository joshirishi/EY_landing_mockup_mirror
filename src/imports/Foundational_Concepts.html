The Evolution of AI

Each layer is a subset of the one before it — building on the last

1943
Artificial IntelligenceSystems designed to perform tasks that normally require human intelligence by following predefined rules and instructions.
Follows rules.
Everyday Examples
  • Traffic lights changing based on a programmed sequence
  • Elevator deciding which floor to visit next
  • Washing machine running selected cycles
Like a Traffic Signal
Rule: If the timer reaches 60 seconds → change to red.
Action: The signal follows the instruction.
1959
Machine LearningAI systems that learn patterns from data instead of only following predefined rules.
Learns from experience
Everyday Examples
  • Netflix recommendations
  • Amazon product suggestions
  • Email spam filtering
Like Your Favourite Food Delivery App
At first, it knows nothing about you.
After many orders:
It starts learning your preferences.
2006
Deep LearningA type of machine learning that uses neural networks to recognize complex patterns
Recognises complex patterns
Everyday Examples
  • Face Unlock on smartphones
  • Voice assistants understanding speech
  • Google Photos recognizing people and objects
Like Listening to a Song and Recognising It Instantly
You may hear only a few seconds.
Yet you immediately know the song.
Not because you memorized rules.
Because your brain has learned complex patterns.
2017–22
Generative AIAI that creates new content such as text, images, audio and code
Creates new content
Everyday Examples
  • ChatGPT drafting content
  • Copilot creating presentations
  • AI image generation
Like A Musician Composing a New Song
You ask:
“Create a relaxing melody for a travel video.”
The musician uses learned knowledge to create something new.
2024
AI AgentAI systems that can plan, decide and execute tasks toward a goal
Acts towards an end goal
Everyday Examples
  • Travel planning assistants
  • Shopping assistants
  • Meeting preparation assistants
Like a Personal Executive Assistant
Instead of simply answering:
“When is my flight?”
It can:
  • Book the flight
  • Reserve the hotel
  • Add the calendar event
  • Send reminders

AI follows exact rules you give it. Machine Learning (next) figures out its own rules from data.

Each level builds on the previous by adding new capabilities. Understanding the difference helps you choose the right tool for the job.

2 — AI AGENT

AI Agent

What is added?
LLM Capability

What it does

Not only answers — but also does things.

Think of it as

A virtual team member.

— reads the notice
— extracts key facts
— drafts a summary
— stores it in the correct folder
Best Used When

—Multiple actions are required
—The process is still relatively simple

Agentic AI

What is added?
LLM
Tools
Tools
Planning

What it does

Manages an entire objective from start to finish.

Think of it as

A project manager.

Prepare an initial response package for a GST notice.

Agentic AI can:

1. Review the notice
2. Identify due dates
3. Gather supporting documents

—Several tasks must be coordinated
