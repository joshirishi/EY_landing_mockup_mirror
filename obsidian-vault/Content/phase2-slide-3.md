# Slide 3 — Good Outcomes Begin with Clear Instructions

**Section:** MEMORY REFRESH  
**Subtitle:** Recall the building blocks—without repeating the full Phase 1 training.

---

## Effective Prompt — 8 Elements

| # | Element | Description |
|---|---------|-------------|
| 1 | **Persona** | Perspective |
| 2 | **Context** | Relevant facts |
| 3 | **Objective** | What AI should do |
| 4 | **Instructions** | Steps and criteria |
| 5 | **Sources** | Material to use |
| 6 | **Output** | Format and detail |
| 7 | **Constraints** | What not to assume or do |
| 8 | **Review** | What the user must verify |

---

## Effective M365 Agent Instructions — 8 Elements

| # | Element | Description |
|---|---------|-------------|
| 1 | **Purpose** | Goal to accomplish |
| 2 | **General guidance** | Directions, tone, restrictions |
| 3 | **Skills** | Support expected |
| 4 | **Workflow** | Steps to follow |
| 5 | **Knowledge** | Approved information |
| 6 | **Errors & limitations** | When to stop or clarify |
| 7 | **Examples** | Appropriate interaction |
| 8 | **Follow-up & closing** | How to complete the exchange |
