# Slide 7 — One Process. Different Activities. Different Solutions.

**Section:** ACTIVITY-LEVEL CHOICE  
**Subtitle:** Illustrative advance-tax mapping from the workbook: classify each activity separately.

---

## Activity Mapping Table (Advance Tax Example)

| ACTIVITY | CURRENT PAIN POINT | POSSIBLE RESPONSE |
|----------|-------------------|-------------------|
| Request projected financials from business units | Multiple follow-ups | **M365 Agent** |
| Collect qualitative tax inputs | Inputs buried in email and Teams | **M365 Agent** |
| Summarise business changes affecting forecast | Manual review of communications and forecasts | **Prompt** |
| Compare current and prior-quarter assumptions | Time spent reviewing historical workings | **Prompt** |
| Prepare variance narrative | Manual drafting | **Prompt** |
| Consolidate business-unit comments | Inputs received through different channels | **M365 Agent** |
| Draft communication to Treasury or business | Recurring communication within a broader workflow | **Prompt and/or Agent — subject to workflow design** |
| Archive challans, approvals and supporting files | Manual document organisation | **M365 Agent** |

---

## Decision Framework

### Consider a Prompt
- User-initiated task
- Defined input
- Interpretation, review or drafting
- Output varies with facts
- Professional closely involved

### Consider an Agent
- Activity repeats
- Multiple people or repositories
- Collection, retrieval or tracking
- Workflow can be instructed
- Outputs and escalation can be defined

### Consider both
- Agent coordinates or retrieves
- Prompt interprets, analyses or drafts

---

> **Do not classify an entire tax process as "Prompt" or "Agent." Assess each activity separately.**
