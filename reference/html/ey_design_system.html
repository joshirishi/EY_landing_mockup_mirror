Sizing & positioning

Preferred position is bottom-right for print/digital; top-right for advertising. Our Frames · Spectrum Frame

The Frame — anatomy

The top angle mirrors the beam in the EY logo; the three squares mirror the Approach Line. Default position is left, horizontally centered, with sufficient clearance from logo and Approach Line/Indicator.

Never obscure more than 25% of the Frame with imagery, and never cover the three indicator squares.

Our Frames · Spectrum Frame

Selecting the color of your Spectrum Frame

1. Select an image

Choose imagery following the photography principles. Identify highlight colors present in the image that match the Spectrum palette.

2. Select the gradient

In Illustrator, select the Frame stroke (excluding the 3 squares), then choose the predefined gradient from Swatches that accentuates the image's highlight colors.

3. Add the Frame

Place the chosen Spectrum Frame over the image, masking as needed.

Our Frames · Breakthrough Frame

Breakthrough Frame — introduction

A typographic Frame treatment that elevates the Spectrum Frame suite further: the headline visually breaks through the Frame itself, split roughly in half across the Frame's width, for bolder hero-level composition. Follows the same sizing/color rules as the Spectrum Frame plus the rules below.

Our Frames · Breakthrough Frame

Breakthrough questions — copy & type rules

Writing the question

  • No longer than 75 characters
  • Must make sense when split in the middle
  • Closing question mark always present
  • Set in EY Interstate Bold, staggered along a baseline grid

Sub-heading / CTA

  • Sub-heading ≤ 100 characters
  • CTA ≤ 30 characters
  • Combined ≤ 130 characters
FormatRecommended type size
16:9 (1920×1080px)88pt
Social square (1080×1080px)70pt
US Letter (8.5×11")40pt

±20% tolerance allowed for short questions or long words, provided margin/clear-space rules are still met.

Our Frames · Breakthrough Frame

Composing layouts — asset placement checklist

  • Better question set in EY Interstate Bold, ≤75 characters?
  • Question split at a natural, logical point?
  • Vertical type alignment used where possible against the Frame's arms?
  • Body copy ≤130 characters incl. CTA, clear of right margin and logo?
  • Approach Line and Indicator sized and positioned correctly?
  • Image focal point held within the Frame and clearly visible?
  • Logo sized and positioned correctly (bottom right)?

If your assets don't fit this checklist, fall back to the standard Spectrum Frame guidance instead.

Our Frames · Breakthrough Frame

Don'ts

✕ Don't

Use overly long questions — keep under 75 characters.

✕ Don't

Break questions unnaturally — ensure a logical flow at the split point.

✕ Don't

Use differing font sizes within one question.

✕ Don't

Force left/right/center align — aim for a dynamic staggered layout.

✕ Don't

Make the question too small — always prioritize readability.

✕ Don't

Place the question over key image focal points.

✕ Don't

Place an image's focal point outside the Frame.

✕ Don't

Break the question unevenly — avoid one side being much longer.

Our Frames · Yellow Frame

Yellow Frame

The original single-color Frame treatment remains an important, available asset. All Frame assets — including the Yellow Frame — are now built from a single thick stroke (not outlined artwork); always use the latest asset files. Follows identical sizing, positioning, and type guidance as the Spectrum Frame. Statements are now permitted inside the Frame, so the older "EY Panel" device is no longer used. Note: the Yellow Frame cannot be used as a Breakthrough Frame — only Spectrum Frames support that treatment.

05 · Spectrum Shapes

Overview

Vibrant, fluid abstract backgrounds built from the Spectrum color palette. Symbolize EY's forward-thinking mindset and energy. Used for event backdrops, digital content, merchandise, badges, and printed materials — always via dynamic crops of the master shape asset to keep a consistent, impactful visual presence. Never construct these freehand; use supplied master files and crop/scale as needed.
