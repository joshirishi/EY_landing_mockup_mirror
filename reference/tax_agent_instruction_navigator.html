Drafting blueprint

Use this as the memory aid when drafting instructions later for tax use cases. It does not add new technical content; it organizes the source material into a practical drafting sequence.

Purpose and scope

Use clear, actionable language. Define what the agent must do. State what knowledge, capabilities and actions the agent should use.

Tax vocabulary

Define acronyms, tax terms, internal terms and specialized formulas so the agent does not have to infer meaning.

Workflow design

Break work into atomic steps. Separate parallel tasks from sequential tasks. Use transitions where the next step depends on the previous step.

Decision rules

Use if/then rules for missing facts, conflicting inputs or changed conditions. Ask for clarification when key information is missing.

Output contract

Specify tone, verbosity, output format and length expectations so the response does not become verbose or over-formatted.

Markdown structure

Use headings, bullets and numbers deliberately. Bullets for parallel tasks. Numbered steps for sequences. Bold critical instructions.

Examples and variation

Provide examples for complex scenarios. Encourage varied professional language for drafting tasks that may otherwise repeat phrasing.

Validation and improvement

Add a self-check step before finalizing. Test, verify and update instructions, examples and knowledge sources from time to time.
